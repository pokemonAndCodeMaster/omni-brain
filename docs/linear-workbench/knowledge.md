## 目录怎样更新

每次新增、改名或调整文档归属后，由 Agent 获取当前工作区完整文档清单，更新此处目录并发布回同一篇文档。目录的核对日期表示本次覆盖范围，不是后台自动同步的保证。文档正文是否最新，以点击后的原文为准。

你可以说：“刷新工作台的完整文档目录和本地阅读页。”Agent 会取得全部分页及需要的全文，更新目录和阅读快照。挂在事项里的方案、团队资料和项目文档都应能找到；缺少访问权限时应说明缺口。

新增成果先放回所属主题，再补入口。已有主题继续维护原文，不按每次聊天创建一份副本。正式知识和代码可以独立阅读，事项保留它们形成、修改与验证的过程。
