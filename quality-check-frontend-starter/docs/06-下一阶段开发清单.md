# 06. 下一阶段开发清单

## P1：把 Starter 变成正式共享组件

- 将 `AnalysisBuilder` 从 `DeliveryRow` 解耦；
- 建立 `DataSourceSpec`、`FieldDefinition`、`MetricDefinition` 注册表；
- 业务 feature 只注册字段和指标；
- 增加文本、枚举、数值、日期、空值、标签等筛选器；
- 增加多层 AND/OR 高级筛选 UI；
- 将 QuerySpec 写入 URL。

## P2：服务端表格语义

- 服务端排序；
- 游标分页；
- 服务端层级展开；
- `SelectionSpec` 跨页全选；
- 导出当前页、当前筛选全部和选中行；
- 虚拟滚动接入 `@tanstack/vue-virtual`。

> Starter 已安装 `@tanstack/vue-virtual`，但第一纵切暂未启用，避免初学阶段同时理解表格状态和虚拟化测量。

## P3：编辑和高风险动作

- 单元格保存中状态；
- 乐观更新和失败回滚；
- 行级版本号；
- 批量普通字段编辑；
- preview → confirm → execute → refresh；
- preview 过期和输入变化失效；
- 部分成功、跳过、失败明细；
- 审计记录。

## P4：分析语义层

- 后端聚合 API；
- 指标注册表；
- 比率使用 ratio-of-sums；
- 时间粒度、Top N、分桶、排序；
- 图表推荐；
- 图表数据点下钻；
- ChartSpec 只存查询和配置，不长期缓存结果。

## P5：卡片和看板正式化

- `CardSpec` 与 `CardInstance` 分离；
- 一卡多内容原子；
- 看板全局筛选；
- snapshot/dashboard/merge 三种筛选绑定；
- lg/md/sm 多断点布局；
- 草稿、发布、版本、回滚；
- 公共、团队、个人所有权；
- 普通用户修改公共卡片时自动另存个人副本。

## P6：工程质量

- Vitest 单元测试；
- Playwright 端到端测试；
- ESLint + Prettier；
- API 类型自动生成；
- 路由级动态 import，减小首包；
- ECharts 按需导入；
- 错误边界、埋点和性能监控；
- 无障碍键盘测试。
