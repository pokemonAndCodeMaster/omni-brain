# 交付任务的四条状态轴

| 状态轴 | 回答的问题 | 示例 |
|---|---|---|
| 阶段 | 业务走到哪一步 | 标注、验收、交付 |
| 健康 | 当前是否有风险 | 正常、风险、阻塞 |
| 行动项 | 谁还要做什么 | 待处理、逾期、已完成 |
| 验收/结论 | 质量判断是什么 | PENDING、PASS、REJECT |

四条轴描述不同事实，所以“验收 PASS、外部执行回查中、交付有风险”可以同时成立。PASS 只说明质量结论允许进入后续动作；交付完成还要确认外部状态、可交付 Good 数量和交付目标。REJECT 则必须进入返工，不是任务结束。

当前知识冻结的是交付任务、行动项和交付中心的长期边界；真实交付服务、预测算法、提醒、页面/API 是否上线仍无直接证据，不能从目标工作台描述推出生产事实。
