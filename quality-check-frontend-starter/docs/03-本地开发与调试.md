# 03. 本地开发与调试

## 一、安装工具

推荐安装：

1. Node.js 22.18+ 或 24.11+；
2. Git；
3. VS Code；
4. Chrome 或 Edge；
5. VS Code 扩展：Vue - Official（Volar）。

检查：

```bash
node -v
npm -v
git --version
```

## 二、第一次启动

```bash
npm install
npm run dev
```

正常输出会包含：

```text
Local: http://localhost:5173/
```

不要直接双击 `index.html`。Vite 工程必须通过开发服务器运行。

## 三、VS Code 调试

工程已包含：

```text
.vscode/launch.json
.vscode/tasks.json
.vscode/extensions.json
```

操作：

1. 在 VS Code 终端运行 `npm run dev`；
2. 打开左侧“运行和调试”；
3. 选择“Chrome: 调试 Vite 页面”或 Edge；
4. 按 F5；
5. 在 `.vue` 或 `.ts` 中点击行号设置断点。

推荐先在这些位置下断点：

- `DeliveryWorkbenchPage.vue` 的 `handleCellEdit`；
- `AnalysisBuilder.vue` 的 `addToDashboard`；
- `dashboard.ts` 的 `updateLayouts`；
- `deliveries.ts` 的 `getDeliveries`。

## 四、浏览器开发者工具

按 F12：

### Console

看 JavaScript 错误和 API 错误。

### Network

接真实后端后重点看：

- URL；
- HTTP 方法；
- Request Payload；
- Status Code；
- Response；
- 耗时。

### Application → Local Storage

可以看到：

```text
quality-check.dashboard.cards
quality-check.delivery-workbench.views
```

删除这些 Key 可以清空个人配置。

## 五、修改代码后的反馈

Vite 支持热更新：

- 改 `.vue` 模板通常不刷新整页；
- 改 CSS 立即更新；
- 改环境变量必须重启；
- 改路由后遇到异常可手动刷新。

## 六、调试类型错误

运行：

```bash
npm run type-check
```

常见问题：

### `Type 'string' is not assignable to ...`

说明后端或选择框返回了任意字符串，但类型只允许固定枚举。不要简单全改成 `any`，应校验值或收窄类型。

### `possibly undefined`

说明数组索引、Map 查询或可选字段可能没有值。需要显式处理空值。

### Vue 模板中组件报红但能运行

确认安装 Vue - Official，禁用旧版 Vetur，重启 TypeScript Server。

## 七、调试接口代理

`.env.development`：

```env
VITE_USE_MOCK=false
VITE_API_BASE_URL=/api/v1
VITE_API_PROXY_TARGET=http://127.0.0.1:8000
```

请求：

```text
浏览器请求 /api/v1/manual-qc/deliveries
Vite 转发到 http://127.0.0.1:8000/api/v1/manual-qc/deliveries
```

这样开发期通常不需要后端额外配置 CORS。

## 八、常见启动问题

### 端口 5173 被占用

工程启用了 `strictPort`，会直接报错。Windows 查询：

```powershell
netstat -ano | findstr :5173
taskkill /PID <PID> /F
```

### `npm install` 很慢

先确认公司代理、证书和 npm registry。查看：

```bash
npm config get registry
npm config list
```

### Node 版本不满足

使用 nvm-windows 或 fnm 切换 Node。升级后删除：

```bash
rm -rf node_modules package-lock.json
npm install
```

Windows PowerShell：

```powershell
Remove-Item node_modules -Recurse -Force
Remove-Item package-lock.json -Force
npm install
```
