# 开放问题

本页是摄入案中缺口、冲突和待确认事项的**唯一状态源**。`review.md` 和知识正文
只引用这里的问题 ID 与影响，不另维护一套未知状态。

| ID | 问题 | 为什么会改变结果 | 需要的来源/人员 | 当前状态 | 答案、证据或当前缺口 | 允许的下一动作 |
|---|---|---|---|---|---|---|

当前状态使用 `open / answered / accepted_unknown`。不要把“没有找到”写成“不存在”；
已回答问题保留答案和证据链接，不删除历史问题。若当前没有开放问题，明确写出
“无开放问题”及其依据，不能只留下空表。
