# 质检知识入口路由用例 v1

## 用户结果

用户用自然语言问一个已有知识问题时，Harness 在模型读取正文前返回一个最可能直接回答问题的规范页绝对路径，以及最多两个候补。路由只帮助选入口，不回答问题，不读取原料，不形成持久索引。

## 固定输入

- 路由组件：`.agents/skills/answer-from-knowledge/scripts/knowledge_route.py`；
- 正式知识：`omni-brain-harness-quality-check-v1@900cf85`；
- 用例：[cases.yaml](cases.yaml)；
- 每题允许一个小集合的语义等价主入口，避免把专家偏好的唯一文件路径当成真理。

通过要求：10 题主入口全部落在允许集合；跨主题问题还要由前三个结果覆盖声明的补充主题。所有返回路径必须绝对、存在且位于正式知识根；未链接的知识副本不能参与排序；组件零写入。确定性路由通过只证明入口选择，不证明最终答案正确或弱模型会遵守 `PRIMARY` 停止规则。
