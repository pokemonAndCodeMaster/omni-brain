# YYH-12 原生 Views 交付证据

用户要求在 Linear 本身按日常场景选事，并授权通过官方 API 保存五个既定视图、查重保留身份、验证实际命中、收藏和默认首页。基线及源码身份见 [manifest.json](manifest.json)。本次不建设另一套任务界面，不改变知识分类、原始材料或工作区全局默认首页。

[verified.json](verified.json) 是最终真实 API 回读：五个筛选和命中结果一致，收藏身份与排序一致；检查时命中 9、0、1、2、5 条。布局、分组、排序与编号、状态、优先级一致。项目、标签两列保存为显示但最终显示值为隐藏；默认首页未设置，原生浏览器未验证。验证命令退出码 0 不意味着这些未通过条件已完成。

[repeat-check.json](repeat-check.json) 对比两次真实执行，五个视图 ID、收藏 ID、排序和 View 更新时间不变。创建失败响应不自动重试，下一次先查当前对象。为排查列显示差异，本次曾仅在新建“现在推进”视图上添加一条默认偏好；未解决差异，已按精确 ID 删除并回读为空，个人偏好保留。完整写前快照和该恢复记录保存在主仓忽略提交的运行归档，未提交密钥或账号登录数据。

独立复核先发现偏好更新漏读已弃用字段，见 [原探针](initial-review-probe.py) 和 [失败结果](initial-review-result.json)。修复为包含弃用字段的完整读取，新增严格字段投影回归；新上下文用官方 Schema 构造 248 个字段，确认 238 个非本功能字段、5 个弃用字段、false、空列表与嵌套数组保留，第二次不再写偏好，见 [新探针](preference-review-probe.py) 和 [结果](preference-review-result.json)。这是离线复核，不替代真实 API 或浏览器观察。候选 stdlib 单元测试 10 项通过。

执行工作树按 manifest 中的归档 ref 保留版本后回收。探针是当时命令的原始记录，包含原执行路径；复放时按 manifest 重建工作树，并提供指纹一致的官方 Schema。通常维护直接使用主仓 `scripts/linear_views.py`，具体调用与身份边界见 [README](../../../../docs/linear-workbench/README.md)。YYH-12、线上视图方案、工作台项目 Overview 和使用说明已原位更新；知识浏览与真实页面的剩余范围继续在同一事项跟踪。
