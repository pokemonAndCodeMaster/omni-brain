# 质量通过率的当前实现结论

**当前不能在两种分母中直接选一个作为生产规则。** 三阶段语义和快照材料支持“通过数 / 已完成验收数”，规则设计的输入段又写成“通过数 / 已分配验收数”，现有知识把它保留为未裁决冲突。

- `通过 / 已完成`：只评价已经做出验收判断的样本质量；
- `通过 / 已分配`：会把尚未完成的验收也纳入分母，因此同时受到进度影响；
- `已完成 / 已分配`：应单独作为**验收完成进度**，不要与质量通过率共用一个无公式标签。

页面在裁决前必须显式展示指标公式与数据时间。最小下一步是由业务负责人确认完成进度和质量判断各自的分子、分母与边界，并给出当前有效规则/产品口径及一组包含未完成样本的代表性数据；开发者再用当前 Schema/运行查询确认字段可得性。历史 95%、0.9499 和 0.7999 只属于历史做法，不能自动成为当前实现。
