# Omni-Brain Harness 真实能力路线

本项目只用真实用户结果表达进度。可移植性、治理、状态、索引和 Eval 横切各阶段，不单独构成产品阶段。

| 阶段 | 用户能实际完成什么 | 当前状态 |
|---|---|---|
| M1 | 把混乱真实材料整理并摄入为可浏览、可查询、可追溯的知识 | V9 已窄修来源主题地图、有界阅读和初稿内容回环，等待相同真实工况前向验证 |
| M2 | 立即知道已有、缺失、冲突、可信范围和补知责任 | 未开始，必须消费 M1 真实知识 |
| M3 | 知识进入真实业务/开发任务并形成经过运行验证的结果 | 未开始 |
| M4 | 代码、规则和流程变化后，知识与视图安全演进 | 未开始 |
| M5 | 已跑通能力在另一领域、更多模型和更大规模下仍可用 | 未开始 |

后一阶段必须真实消费前一阶段产物。脚本、Schema、Skill、测试数和扫描报告不能单独证明阶段完成。

M1 只有在用户使用另一模型完成真实材料盘点、人工门禁、规范知识发布、两种产品视图、只读检查和真实问题消费后，才可能成为 `verified@slice`。当前实现不能跳过这一步。
