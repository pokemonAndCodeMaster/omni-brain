# Omni-Brain Harness 真实能力路线

本项目只用真实用户结果表达进度。可移植性、治理、状态、索引和 Eval 横切各阶段，不单独构成产品阶段。

| 阶段 | 用户能实际完成什么 | 当前状态 |
|---|---|---|
| M1 | 把混乱真实材料整理并摄入为可浏览、可查询、可追溯的知识 | 独立 Harness 已发布；首个质检增量切片完成人工批准、正式消费和跨模型重放 |
| M2 | 立即知道已有、缺失、冲突、可信范围和补知责任 | 下一阶段；本 Release 尚未实现 |
| M3 | 知识进入真实业务/开发任务并形成经过运行验证的结果 | 已在同一质检领域完成页面/契约、只读 SQL 性能和跨层算法三类真实切片；发布为限定范围能力，不外推为跨领域开发已经验证 |
| M4 | 代码、规则和流程变化后，知识与视图安全演进 | 已形成代码回写工作流、强参考和四轮 Luna 盲测；最新候选 22/24，隔离、完整数据契约、固定验证证据发现、父知识融合和视图同步成立，内容深度仍待下一真实切片反证 |
| M5 | 已跑通能力在另一领域、更多模型和更大规模下仍可用 | 未开始 |

后一阶段必须真实消费前一阶段产物。脚本、Schema、Skill、测试数和扫描报告不能单独证明阶段完成。

当前 Release 汇集 M1 摄入、M3 带知识开发和 M4 代码回写能力本体，知识库保持为空；已批准的质检知识位于独立领域集成版。M1 与 M3 只在各自声明的质检切片内验证；M4 为已实现且经过真实盲测、但尚未通过全部内容题的试用能力。跨领域、OpenCode 实际宿主、部分批准与发布回滚仍待后续真实用例验证。
