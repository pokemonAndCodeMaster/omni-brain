# Omni-Brain Harness 真实能力路线

本项目只用真实用户结果表达进度。可移植性、治理、状态、索引和 Eval 横切各阶段，不单独构成产品阶段。

| 阶段 | 用户能实际完成什么 | 当前状态 |
|---|---|---|
| M1 | 把混乱真实材料整理并摄入为可浏览、可查询、可追溯的知识 | 首个质检增量切片已正式发布并完成跨模型重放 |
| M2 | 立即知道已有、缺失、冲突、可信范围和补知责任 | 当前阶段，从 M1 正式知识上的真实查询开始 |
| M3 | 知识进入真实业务/开发任务并形成经过运行验证的结果 | 未开始 |
| M4 | 代码、规则和流程变化后，知识与视图安全演进 | 未开始 |
| M5 | 已跑通能力在另一领域、更多模型和更大规模下仍可用 | 未开始 |

后一阶段必须真实消费前一阶段产物。脚本、Schema、Skill、测试数和扫描报告不能单独证明阶段完成。

M1 已是 `verified@quality-check-incremental-slice`。M2 必须直接消费正式知识，以正确性、边界表达、漏召回、无效阅读和停止理由证明能力，不能把全文通读当作查询实现。
