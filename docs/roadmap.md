# Omni-Brain Harness 真实能力路线

本项目只用真实用户结果表达进度。可移植性、治理、状态、索引和 Eval 横切各阶段，不单独构成产品阶段。

| 阶段 | 用户能实际完成什么 | 当前状态 |
|---|---|---|
| M1 | 把混乱真实材料整理并摄入为可浏览、可查询、可追溯的知识 | 独立 Harness 已发布；首个质检增量切片完成人工批准、正式消费和跨模型重放 |
| M2 | 立即知道已有、缺失、冲突、可信范围和补知责任 | 实验分支已在质检可信问答切片验证；尚未发布或完成第二领域反证 |
| M3 | 知识进入真实业务/开发任务并形成经过运行验证的结果 | 同一质检领域完成三类独立开发切片；可信知识路由到开发的首个复合切片已达冻结接受线，仍待第二工程或领域反证 |
| M4 | 代码、规则和流程变化后，知识与视图安全演进 | 代码回写路径已实现并在两个相邻切片取得接近接受线的内容证据，仍需人工审查；下一步用固定复合开发提交验证实际规范知识候选 |
| M5 | 已跑通能力在另一领域、更多模型和更大规模下仍可用 | 未开始 |

后一阶段必须真实消费前一阶段产物。脚本、Schema、Skill、测试数和扫描报告不能单独证明阶段完成。

当前 Release 发布 M1 Harness 能力本体，知识库保持为空；已批准的质检知识位于独立领域集成版。M1 成熟度为 `verified@quality-check-incremental-slice`，跨领域、OpenCode 实际宿主、部分批准与发布回滚仍待后续真实用例验证。
