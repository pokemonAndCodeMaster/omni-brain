# 知识健康检查技能（knowledge-health）

## 触发条件

- 用户要求"检查知识库"、"做一次体检"
- 长时间未检查（建议每月一次）
- 大量摄入后的质量检验

## 执行流程

### 第 1 步：重编译索引（确保数据最新）

```bash
python scripts/compile_index.py
```

### 第 2 步：运行健康检查

```bash
python scripts/health_checker.py
# 输出结构化的健康报告
```

### 第 3 步：LLM 补充分析

在脚本报告基础上，额外检查：
- **冗余检测**：标题/内容高度相似但未被标记为重复的卡片
- **矛盾检查**：标记为 `contradicts` 关系但正文未明确说明取舍的卡片对
- **缺页检查**：`index.md` 或正文中引用了不存在的卡片名
- **质量检查**：缺少 `description` 字段、缺少 `relations` 的孤立卡片

### 第 4 步：输出健康报告

报告写入 `knowledge/synthesis/HEALTH_REPORT_YYYYMMDD.md`，格式：

```markdown
# 知识库健康报告 [YYYY-MM-DD]

## 总览
- 卡片总数：N
- 健康卡片：N
- 问题卡片：N（需要关注）

## 🔴 冲突（需立即处理）
| 卡片A | 卡片B | 冲突描述 |
|---|---|---|

## 🟡 过时（建议更新）
| 卡片 | 过时原因 | 建议操作 |
|---|---|---|

## ⚪ 孤岛（无任何关系链接）
| 卡片 | 建议操作 |
|---|---|

## 🔵 缺页（被引用但不存在）
| 引用来源 | 缺失卡片 | 建议操作 |
|---|---|---|

## 🟢 改进建议
- [具体建议]
```

## 硬规则

- **只输出报告，不执行任何删改**
- 所有建议操作等待人工审批后执行
- 报告中对每个问题给出具体可行的修复建议
