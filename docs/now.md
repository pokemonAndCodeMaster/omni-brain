M1 已完成两轮 Luna 真实 Trial：第二轮修复了来源计数、工作台入口和交接链接，但内容仅小幅改善，并暴露覆盖声明夸大、Markdown 表格损坏、产品视图重复和结构通过被误写成内容完成。当前第三版状态是 `implemented_after_second_trial_awaiting_retest`，正式知识仍为空，也没有参考答案泄漏到本项目。

## 当前可用

- OpenCode 原生根路由；
- `ingest-knowledge` 的盘点、候选编织、人工门禁、发布与立即消费流程；
- `ingestion_workspace.py` 的机器来源清单、Agent 覆盖声明、固定根入口、内容声明契约和结构门禁；
- 空 OKF Bundle、领域地图和两类产品视图入口；
- 标准 Markdown 相对链接约定与只读链接/入链检查；
- 已有任务案和本地 Git 来源范围能力。

- 真实材料能否形成高质量规范知识与产品视图；
- 算法细节、现实形态、冲突和未知能否保持准确；
- 用户审查负担是否可接受。
