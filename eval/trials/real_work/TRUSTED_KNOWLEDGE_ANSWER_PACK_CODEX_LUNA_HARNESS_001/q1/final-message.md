人工质检验收的位置：质检平台下有人工质检、大模型质检、自动化质检等子域；验收属于人工质检内部，位于“标注结果”之后，连接质量判断、通过/打回执行、返工和交付确认。

业务主线：

`需求/规则/数据/人员准备 → 标注 → 抽样与分配验收 → 验收判断与统计 → 形成 PASS/REJECT/PENDING → 执行通过/打回 → 回查真实状态 → 返工再验或确认可交付结果`

验收不等于点“通过/打回”，因为：

- 验收样本只是抽样集，不是要执行的标注全集。
- 验收记录是逐条判断，质量结论还需要完成度、分类结果、规则和适用范围支撑。
- PASS 后仍要对明确范围执行、回查外部真实状态，并确认可交付 Good 数量。
- REJECT 后进入返工、重新提交、抽样和再次验收。
- 数据不足或状态不确定时应补验/补数据或继续回查，不能强行下结论。
